# Contributing

Contributions are welcome! Whether it's improving the adversarial agent prompts, adding new meal vision parsers, or expanding biomechanical rehab rules, feel free to open a Pull Request.

### How to Contribute
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/your-feature`).
3. Commit your changes (`git commit -m 'Add new rehab guardrail'`).
4. Push to the branch (`git push origin feature/your-feature`).
5. Open a Pull Request and sign the automated **Contributor License Agreement (CLA)**.
